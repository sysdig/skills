> **Autogenerated — do not edit by hand.** Values are derived from the current

This is the single source of truth for the look of HTML artifacts produced by
the artifact-generating skills (onboarding summary, runtime investigation
report). When a skill emits a self-contained HTML file, it MUST use the
`<style>` block below verbatim (and, for diagrams, the Mermaid section). This
keeps every artifact on-brand and consistent.

Colors come from the current Sysdig semantic theme (neutral light + dark). The
theme is intentionally monochrome — links and accents are near-black in light
mode and near-white in dark mode — so links are underlined to stay
distinguishable. The pale **lumin** green (`#bdf68b`) is a brand accent used
for the top bar and logo mark only.

## How a skill uses this file

1. Read this file when generating an HTML artifact.
2. Copy the `<style>` block into the page `<head>` verbatim.
3. Add the **brand header** snippet as the first child of `<body>`.
4. For pages with Mermaid diagrams, use the **Mermaid** classDefs + init config.
5. Do not invent colors. If you need a swatch, take it from the token table.
6. **Headings use sentence case** — capitalize only the first word (plus genuine
   proper nouns: Sysdig, AWS, GCP, Azure, Terraform, CVE, IAM, MITRE tactic names).
   Do not Title-Case headings (write "Capabilities enabled", not "Capabilities Enabled").

The shipped artifact follows the reader's OS light/dark preference automatically
(`prefers-color-scheme`). To force a theme (e.g. for a saved example), set
`data-theme="light"` or `data-theme="dark"` on the `<html>` element.

## Mermaid (diagram-bearing artifacts)

Use these Sysdig `classDef`s in every `flowchart` (paste at the bottom of the
diagram, regardless of which classes are used), and this `mermaid.initialize`
config. Category color carries meaning here, so these use the Sysdig brand
supplementary palette (falco blue / risk red) plus neutral grey rather than
the monochrome theme accent. Node fills are light with a fixed dark text color so
they stay legible under both the `default` and `dark` Mermaid themes.

```
classDef entrypoint fill:#d6f7fb,stroke:#00cbe2,stroke-width:2px,color:#1f2326;
classDef malicious  fill:#ffe5e6,stroke:#ea5255,stroke-width:1px,color:#1f2326;
classDef cloud      fill:#dde3e7,stroke:#6c7480,stroke-width:1px,color:#1f2326;
classDef external   fill:#f0f3f5,stroke:#8c939b,stroke-width:1px,stroke-dasharray:4 2,color:#1f2326;
```

```js
const sdDark = window.matchMedia('(prefers-color-scheme: dark)').matches;
mermaid.initialize({
  startOnLoad: false,
  theme: sdDark ? 'dark' : 'default',
  themeVariables: {
```
